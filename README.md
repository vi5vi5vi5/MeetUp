# MeetUp

**Говорите свободно.**

Открытый сервис видеозвонков, который живёт на вашем сервере, а не в чужом облаке.
Без регистрации по телефону, без рекламы, со сквозным шифрованием.

## Зачем это

Связь всё чаще выключают сверху. Привычные мессенджеры и звонилки перестают работать не потому, что сломались, — просто кто-то наверху решил, что так надо. VPN выручает, пока не заблокируют и его.

Дело не в конкретном приложении, а в том, что за ним стоит одна компания и один адрес, которые нетрудно придавить. MeetUp убирает эту точку опоры. Здесь нет центрального сервиса — каждый поднимает свой. Блокировать нечего: серверов ровно столько, сколько людей.

Вы ставите MeetUp на свою машину одной командой, даёте ссылку друзьям — и разговариваете. Звонок идёт через ваш сервер и зашифрован так, что содержимое не видит даже он.

## Что это даёт

- **Анонимность по умолчанию.** Чтобы позвонить, не нужны ни телефон, ни почта — достаточно ввести имя. Аккаунт (если захочется своя постоянная комната) — это просто логин и пароль.
- **Сквозное шифрование.** Видео, звук и переписка шифруются прямо на вашем устройстве (AES-256-GCM). Сервер пересылает поток, но прочитать его не может: ключ есть только у собеседников.
- **Ваш сервер — ваши правила.** Никто не ведёт логи, не крутит рекламу и не может выдать вашу переписку по запросу. Выдавать нечего, да и спрашивать не у кого.
- **Всё открыто.** Исходный код и протоколы лежат здесь целиком. Любой может заглянуть внутрь, проверить, найти ошибку или собрать на этой основе своё.

Открыто для людей — закрыто для тех, кто хочет подслушать или запретить.

И это не только про личные звонки. Компания или команда может поставить MeetUp на свой сервер и не гадать, куда уходят записи переговоров: коммерческая тайна, внутренние документы и служебная переписка остаются внутри, а не в чужом дата-центре.

## Как начать

### Просто позвонить

Свой сервер нужен не сразу и не всем — уже работает открытый тестовый сервер разработчика: **`meetup.linkpc.net`** (Финляндия). Можно ничего не настраивать:

- **Через браузер.** Откройте [`https://meetup.linkpc.net/`](https://meetup.linkpc.net/) в Chrome, Edge или Firefox, введите имя и код комнаты. Ставить ничего не нужно — работает и на компьютере, и на телефоне.
- **Приложением для Windows.** [Скачайте клиент](https://github.com/vi5vi5vi5/MeetUp/releases/latest), распакуйте и запустите `Win11Client.exe` — он подключается к `meetup.linkpc.net` или к любому другому серверу MeetUp.

Содержимое звонка в любом случае шифруется на вашем устройстве — даже чужой сервер видит только шифротекст. А для полной независимости поднимите свой, это недолго.

### Поднять свой сервер

Нужен компьютер, который всегда включён, — недорогой VPS или домашняя машина. Всё ставится из консоли:

```bash
# 1. Установить Docker (официальный скрипт, Linux)
curl -fsSL https://get.docker.com | sudo sh

# 2. Скачать MeetUp и запустить
git clone https://github.com/vi5vi5vi5/MeetUp.git
cd MeetUp/Server
./tools/update.sh --force
```

Скрипт соберёт и запустит всё сам. Первая сборка занимает несколько минут; потом сервер отвечает по адресу `https://<ip-вашего-сервера>/` — откройте его и поделитесь ссылкой с друзьями.

Есть свой домен? Укажите его — сервер сам получит настоящий сертификат, и браузер перестанет предупреждать о безопасности:

```bash
./tools/update.sh --force --domain ваш-домен.ru --email you@mail.com
```

На Windows поставьте [Docker Desktop](https://docs.docker.com/desktop/install/windows-install/) (или `winget install Docker.DockerDesktop`), а команды выполняйте в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File tools\update.ps1 -Force -Domain ваш-домен.ru -Email you@mail.com
```

Чтобы позже обновиться до свежей версии, запустите тот же скрипт без `--force`: он подтянет изменения и пересоберёт только то, что поменялось. Подробности про порты, домены и сертификаты — в [`Server/README.md`](Server/README.md) и [`Server/proxy/`](Server/proxy/).

## Из чего это сделано

Три части, все в этом репозитории.

**Сервер** — [`Server/`](Server/)
C++20 и Qt6 (Core, Network, WebSockets). Работает ретранслятором: принимает сжатые кадры и раздаёт их участникам комнаты, не заглядывая внутрь, — поэтому лёгкий и добавляет минимум задержки. Аккаунты и комнаты держит в одном файле SQLite, веб-клиент раздаёт сам. Разворачивается через Docker; HTTPS и сертификаты Let's Encrypt берёт на себя nginx-прокси.

**Веб-клиент** — [`Server/web/`](Server/web/)
React, открывается в браузере без установки. Кодирует видео через WebCodecs (H.264/VP8/VP9) и звук через Opus прямо на странице. Сквозное шифрование — AES-256-GCM на устройстве.

**Клиент для Windows** — [`Win11Client/`](Win11Client/)
Нативное приложение на Qt6 Quick (QML). Видео и звук кодирует через ffmpeg (openh264, libvpx) и Opus, умеет демонстрацию экрана и глобальные горячие клавиши, шифрует так же, как веб-клиент. Полные исходники — в [`Win11Client/`](Win11Client/), готовая сборка — в [релизах](https://github.com/vi5vi5vi5/MeetUp/releases/latest).

## Разработчикам

Проект специально сделан так, чтобы в нём разобрался обычный программист и смог добавить своё. Серверный код разложен по слоям и подробно прокомментирован; тем, кто не знаком с Qt, поможет раздел «Qt за 5 минут» в [`Server/README.md`](Server/README.md). Все протоколы — HTTP API, WebSocket, формат медиа-кадра, шифрование — описаны в [`Server/docs/`](Server/docs/): по ним можно написать свой клиент под любую платформу.
